# Architecture review artifacts

- `dsh-container-architecture-atlas.html` maps hosts, image inputs, containers,
  writable state, loopback transport, network posture, and security gates.
- `dsh-container-implementation-sequence.html` explains the gated implementation
  sequence and validation exits.
- `evidence-and-gates.html` maps evaluation drivers to the claims they may make
  and the open acceptance backlog.

The HTML files are standalone review artifacts. Open them directly or with
Lavish Editor. Lavish is used for architecture review, not as a substitute for
product UI acceptance.
