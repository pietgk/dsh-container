Decision map

What can each driver actually prove?

Functional success, rendered correctness, official browser interaction, diagnostics, and human confirmation are separate claims. The evaluation records the strongest class achieved without silently promoting a fallback.

Rule of judgement

The Web API proved the four real-model scenarios. It did not prove their rendered transcripts. Playwright now owns repeatable visual evidence; official Browser owns interactive review.

The browser-control alternatives

Repeatable gate

Playwright

Read-only shell, credential indicator, controlled transcript, reload, fatal console errors, and screenshots at 1440x900 and 1024x768.

Interactive path

Official Browser

Use an in-app Browser or Chrome connected through Settings → Computer use. If neither exists, interactive evidence remains blocked.

Qualified fallback

Web API or diagnostics

The API proves functionality. Chrome DevTools can diagnose rendering. Neither may be reported as official interactive review.
